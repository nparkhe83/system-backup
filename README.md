# system-backup

### Instructions

- If git is not installed

  - Install CLI Tools package for [ Mac ](https://developer.apple.com/downloads/)
  - Verify git is installed `git --version`
    <br>

- Clone the repo `git clone https://github.com/nparkhe83/system-backup.git `
  <br>

- Run install.sh script from the cloned repo

### Features

- Requires and sets up the script on its own.
